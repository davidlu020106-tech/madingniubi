# 牛逼马丁不死不休 💪

马丁内核 + 可插拔模块的量化交易系统

**愿景**: 震荡市用马丁快速翻倍，翻倍后提本滚利，收到信号及时停止。

## 快速开始

```bash
pip install ccxt pandas numpy
```

## 项目计划

- [ ] 选币筛选 — 扫全市场找最适合马丁的震荡币
- [ ] 马丁内核 — 倍投加仓引擎
- [ ] 翻倍提取 — 翻倍后自动提本，利润继续滚
- [ ] 风控模块 — 硬止损 + 停止信号
- [ ] FMZ部署 — 移植到发明者量化平台跑实盘

# 牛逼马丁不死不休 💪

马丁内核 + 可插拔模块的量化交易系统 — **部署在 FMZ（发明者量化）平台**

**愿景**: 震荡市用马丁快速翻倍，翻倍后提本滚利，收到信号及时停止。

## ⚠️ 语言规范（重要）

**本项目的运行代码一律用 JavaScript 写**，因为：

1. FMZ 平台对 JS 支持最全（多线程、_G 持久化、Web服务等）
2. 社区参考策略绝大多数是 JS
3. Python 在 FMZ 上有库限制，调试麻烦

Python 仅用于**离线分析/回测/筛选研究**，不用于 FMZ 实盘。

## 部署到 FMZ

1. 打开 [FMZ 策略编辑器](https://www.fmz.com/m/strategy)
2. 新建策略 → 语言选 **JavaScript**
3. 粘贴 `fmz_martin.js` 的内容
4. 配置交易所（OKX 合约）→ 保存 → 运行

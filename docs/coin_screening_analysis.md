## 方法论分类（6大派系）

### 🥇 布林带+RSI区间派（最多，~40个）

**核心思路**: 价格在布林带上下轨之间运行 = 震荡，RSI不极端 = 可以入场

代表作:
1. 动态波幅捕捉RSI-布林带策略 (5维，10KB)
2. 布林带结合超级趋势的智能波动区间交易策略
3. 结合布林带与RSI的自适应震荡趋势交易策略
4. 双重布林带震荡跟踪策略
5. RSI动态区间反转量化策略与波动率优化模型

### 🥈 波动率阀值派（~25个）

**核心思路**: ATR/标准差在某个范围内 = 波动率适中，适合马丁

代表作:
1. 自适应范围波动率趋势跟踪交易策略
2. 动态波动率自适应EMA×RSI交叉策略
3. 历史波动率区间突破交易策略
4. 多指标融合波动率捕捉型自适应趋势跟踪策略

### 🥉 成交量确认派（~20个）

**核心思路**: 震荡行情成交量萎缩，突破放量 — 用成交量过滤

代表作:
1. VWAP交易策略与成交量异常监测
2. 范围量加仓DCA策略
3. 趋势量能突破策略整合EMA与成交量异常监测系统
4. 流动性捕捉与智能资金分歧指标结合策略

### 4️⃣ 选币扫描派（~15个）

**核心思路**: 扫全市场→算指标→排序→选Top N

代表作:
1. **U本位网格振幅筛选** (3KB, ⭐ 最直接参考)
2. 高级量化趋势捕捉策略结合动态范围过滤器
3. 重要区间MACD交叉动量趋势捕捉策略
4. 动态布林带时间范围选择策略
5. 双移动平均线与StochRSI交叉的趋势追踪策略(BlackBit Trader XO Macro Trend Scanner)
6. 测试-关于使用kdj与vol量筛选可能会涨的币种

### 5️⃣ 震荡器/ADX趋势过滤派（~15个）

**核心思路**: ADX低=震荡，高=趋势 → 排除趋势

代表作:
1. 趋势确认随机震荡策略ADX与随机指标结合的动态市场识别系统 (20KB)
2. 自适应ATR-ADX趋势策略V2
3. 基于ATR和ADX的动态三线突破交易策略
4. 双EMA均线与ATR指标配合过滤的趋势跟随策略

### 6️⃣ DCA/网格选币派（~10个）

**核心思路**: 网格和DCA需要震荡行情 → 选币逻辑内嵌在策略里

代表作:
1. 自适应成本均值动态网格策略 (20KB)
2. 智能波动跟踪型DCA策略与双轨止损系统 (22KB)
3. 范围量加仓DCA策略
4. 基于布林通道和RSI指标的渐进DCA策略

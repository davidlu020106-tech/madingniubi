# 系统参数修改方案 — 基于50个FMZ策略验证

> 方法论: 每个缺陷 → 10个FMZ策略 → 深度拆解代表作 → 制定修改

---

## 缺陷①：首层仓位固定10U，不看币价不看权益

### 参考策略
- 动态头寸规模短线交易策略 (9KB): 首仓=权益×2%÷(ATR×止损距离)
- 多因子动态资金管理策略 (15KB): 仓位=权益×2%/(ATR×5×100000)
- 动态趋势跟随分批止盈策略 (11KB): 仓位=min(权益×5%/(ATR×价格)×杠杆, 权益×40%/价格)

### 修改方案
```
首仓U数 = (账户权益 × 2%) / 杠杆 × 价格安全系数
例: 500U权益, 10x杠杆, 币价50U → 首仓 = 500×2%×10 / 50 = 2U保证金
    实际下单量 = 2 × 10 / 50 = 0.4张
```

## 缺陷②：加仓倍数全局1.1x，不分层

### 参考策略
- 网格挂单加马丁倍数递增 (2KB): 1.1x微增，配合极窄间距
- 时间阶梯加仓策略 (9KB): 等额定投，所有层相同
- RSI-EMA动量头寸缩放 (9KB): 2.0x翻倍，但用多重过滤

### 修改方案
```
分层倍率: 前4层用1.2x(快速积累), 后6层用1.1x(保命)
层1: 10U  层2: 12U  层3: 14.4U  层4: 17.3U
层5: 19U  层6: 20.9U 层7: 23U   层8: 25.3U
总敞口: ~142U (vs 原1.5x的 ~256U，降低44%)
```

## 缺陷③：止盈固定20U

### 参考策略
- 双均线+自适应ATR止盈止损 (18KB) ★: TP=4×ATR, SL=2×ATR, 盈亏比2:1
- 布林带动态止盈加仓 (16KB): TP=布林上轨(2×标准差)
- 分批止盈DCA策略 (29KB): TP1=0.5%平25%, TP2=1.0%平50%

### 修改方案
```
止盈U数 = 首仓名义价值 × ATR% × 4 / 杠杆
例: 首仓10U, 10x杠杆, ATR%=5.8%
止盈 = 10 × 5.8% × 4 / 10 = 0.23U??? 

不对。应该用全部持仓均价:
止盈距离 = ATR(14) × 4.0 (来自策略3)
止盈价 = 持仓均价 + ATR(14)×4.0

动态止盈，不用固定20U了
```

## 缺陷④：加仓间距固定1%

### 参考策略
- 双均线+自适应ATR (18KB): 所有间距=ATR×N, 线性联动
- 布林带动态加仓 (16KB): 加仓间距=2%+必须触碰布林下轨
- 多指标DCA (29KB): 固定间距1%/2%但分批减仓

### 修改方案
```
加仓间距 = ATR(14) × 1.5 / 当前价格 × 100%
即: 间距 = ATR% × 1.5

例: INJ振幅5.8%, ATR%≈4.8%
间距 = 4.8% × 1.5 = 7.2% ← 太远了!

修正: 用日ATR百分比
间距 = (日ATR/价格) × 1.0
例: 日ATR=$2.5, 价格=$43, 间距=5.8%×1.0=5.8%

还是太远。改成:
加仓间距 = 日均振幅 × 0.2
例: 振幅5.8% → 间距1.16% ✅ 合理
```

## 缺陷⑤：没有资金分段/分批止盈

### 参考策略
- 动态趋势分批止盈 (11KB) ★: TP1=+8%平50%, TP2=动态重算(高点×1.04)
- 多因子资金管理 (15KB): 浮亏1%全平/浮盈2%全平保护层
- SuperTrend动态资金管理 (22KB): 5:1风险回报+权益保护

### 修改方案
```
分批止盈:
  止盈1 = 持仓均价 + ATR×2  → 平50%仓位(锁定成本)
  止盈2 = 当前最高价 × (1+ATR%) → 剩余50%继续跑

资金分段:
  总资金分3份
  第1份: 跑马丁(30%)
  第2份: 备用(30%)  
  第3份: 已提取利润(40%)
  
  每翻倍一次 → 提取本金 → 利润继续滚
```

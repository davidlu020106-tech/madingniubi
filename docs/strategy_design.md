# 牛逼马丁不死不休 — 策略系统设计

> 基于 FMZ 99+ 策略深度分析，面向"快速翻倍 + 接受爆仓 + 信号止损"的设计

## 核心公式（翻倍速度的数学）

```
翻倍时间 ≈ 止盈间距 / (波动率 × 方向正确率)
加仓速度 ≈ 倍率^层数（multiplier=2.0 时：第10层 = 初始的1024倍）
爆仓边界 ≈ 价格回撤% × 杠杆 / (1 - 保证金率)

示例: 5x杠杆, 20%回撤 → 爆仓
      10x杠杆, 10%回撤 → 爆仓
      multiplier=2.0, 10层 → 累计仓位=初始×1023
```

## 我们的策略设计

### 三层架构

```
┌─────────────────────────────────────────┐
│  第一层: 入场信号（保证首轮成功率）        │
│  MACD金叉 + KDJ金叉 → 双确认开仓          │
│  EMA7>EMA25 → 方向过滤                   │
│  震荡确认（选币系统输出）                  │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│  第二层: 马丁翻倍核心                    │
│  multiplier=2.0, maxLevel=10            │
│  杠杆: 3x-5x（激进可用10x）              │
│  间距: 跌1%触发 → 反弹0.3%确认后加仓     │
│  出金: 翻倍后提取本金，利润滚             │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│  第三层: 信号终止（外部拔电源）            │
│  趋势反转: EMA7<EMA25 → 全平             │
│  回撤终止: 权益回撤>40% → 锁死            │
│  外部信号: TradingView webhook → 强平     │
│  波动率尖峰: ATR翻5倍 → 暂停              │
└─────────────────────────────────────────┘
```

### 关键参数

| 参数 | 推荐值 | 来源 |
|------|--------|------|
| multiplier | **2.0** | 策略3杠杆化马丁（唯一真正翻倍的） |
| maxLevel | **10** | 扛10%回撤，累计仓位1023倍 |
| 杠杆 | **5x**（激进10x） | 暴力马丁用50x，但太危险 |
| 首单 | 账户的0.5% | 赌徒马丁的极小仓位思路 |
| 间距 | 跌1%+反弹0.3% | 策略4 MACD-KDJ金字塔(反弹确认) |
| 入场信号 | MACD+KDJ双金叉 | 策略4，胜率55-65% |
| 止盈 | 持仓均价+目标利润 | 数字货币期货类马丁 |
| 回撤锁死 | 40% | 策略1 SMA终止机制 |
| 均线反转全平 | EMA7<EMA25 | 暴力马丁的趋势过滤思路 |

### 资金管理（赌徒模型）

```
总资金分3份:
  第一份: 跑马丁
  第二份: 备用（第一份爆了顶上）
  第三份: 已提取利润（不动）

每翻倍一次 → 提取本金+50%利润 → 只用剩余50%利润跑下一轮
```

### 首次翻倍成功率最大化

| 措施 | 效果 |
|------|------|
| MACD+KDJ双确认入场 | 胜率从50%→60%+ |
| 选币系统输出震荡币 | 避免在趋势币上做马丁 |
| 反弹确认后才加仓 | 避免抄底在半山腰 |
| 低杠杆(3-5x) | 给加仓留足空间 |
| 10层深度 | 扛10%回撤不爆仓 |
| 信号反转全平 | 趋势来了立即跑 |

## FMZ可以实现吗？

### ✅ 可以直接用FMZ API实现的

```
FMZ内置API:
- exchange.GetRecords() → 计算MACD/KDJ/EMA
- exchange.SetContractType("swap") → 永续合约
- exchange.SetMarginLevel(5) → 杠杆
- exchange.SetDirection("buy"/"closebuy") → 开平仓
- exchange.Buy/Sell → 下单
- _G() → 持久化层数状态
- LogProfit() → 盈亏曲线
```

### ⚠️ 需要自己写的

```
- MACD/KDJ/EMA计算函数（FMZ有TA库但只支持部分指标）
- TradingView webhook接收（用 __Serve 开HTTP服务）
- 翻倍出金逻辑（用 exchange.IO("api"...) 调OKX划转）
```
